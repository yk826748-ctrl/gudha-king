gudha_king - मोबाइल से APK बनाने की शुरुआती परियोजना

महत्वपूर्ण:
यह एक बेसिक DEMO APK project है। इसमें अभी असली Login, OTP, Firebase,
photo/video upload, likes, comments, follow या chat काम नहीं करते।
यह APK बनाने का शुरुआती ढांचा और स्क्रीन है।

मोबाइल से APK बनाने का तरीका (GitHub Actions):
1. ZIP को डाउनलोड करके Extract करें।
2. GitHub पर अपना अकाउंट खोलें और नया Public या Private repository बनाएं।
3. इस ZIP के अंदर की सभी फाइलें repository में Upload करें।
4. Repository में Actions टैब खोलें।
5. "Build gudha_king APK" workflow चुनें और "Run workflow" दबाएं।
6. Build पूरा होने पर workflow run खोलें।
7. नीचे Artifacts में gudha_king-debug-apk डाउनलोड करें।
8. ZIP artifact को Extract करें। अंदर app-debug.apk मिलेगी।

सुरक्षा:
APK केवल अपने भरोसेमंद build से इंस्टॉल करें। Android अगर अनुमति पूछे तो
केवल इसी APK के लिए browser/files app को अनुमति दें। अज्ञात वेबसाइटों से APK न लें।
